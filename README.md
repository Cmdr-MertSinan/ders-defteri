# Ders Defteri

Haftalık ders slaytlarını saklayan, alt sekmede önemli başlıklar altında özetleyen yerel not defteri.

## Ne yapar

- Ders ve hafta oluşturursun.
- **Slaytlar** sekmesinde PDF / PPTX dosyasını yüklersin; orijinal dosya tarayıcıda kalır.
- **Özet** sekmesi slayt metnini büyük başlıklara ayırır, her başlığın altına önemli maddeleri toplar.
- Özeti A4 PDF olarak indirirsin.

Dosyalar bu bilgisayarın tarayıcısında (IndexedDB) durur; bir sunucuya gitmez.

## Açmak

Bu Mac’te henüz Node / Git komut satırı yok. Klasördeki `index.html` dosyasını Cursor’da veya tarayıcıda açman yeterli.

Chrome veya Edge önerilir. İnternet, PDF.js ve PDF indirme kütüphanesi için gerekir.

## Sınır

Taranmış (sadece görüntü) slaytlarda metin olmadığı için özet çıkmayabilir. O durumda slayt yine Slaytlar sekmesinde durur.
